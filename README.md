# Projeto Político

Repositório de investigações político-jornalísticas, baseadas em fatos verificáveis, documentos oficiais e fontes confiáveis.

## Estrutura

- `CLAUDE.md` — diretrizes operacionais permanentes (metodologia, regras, fontes prioritárias e formato exigido para toda investigação).
- `templates/investigacao_template.md` — modelo padrão usado em cada investigação.
- `investigacoes/` — investigações concluídas, uma por candidato/político (`investigacoes/<nome>.md`).
- `roteiros/` — roteiros de vídeo, produzidos apenas mediante autorização explícita a partir de uma investigação já entregue.

## Como usar

Basta informar o nome de um candidato ou político para que uma investigação completa seja produzida seguindo o padrão definido em `CLAUDE.md`.
